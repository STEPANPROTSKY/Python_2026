# Трекер домашней библиотеки

Все книги хранятся в **list**, потому что набор записей постоянно меняется (добавление, удаление) и важен порядок добавления. Одна книга - это **tuple** (`NamedTuple Book(id, title, author, year, tags)`): структура записи фиксирована, а неизменяемость защищает от случайной правки и делает запись hashable; изменение делается созданием новой записи через `_replace`. Для поиска книги по `id` используется **dict** `{id: Book}`, который даёт доступ за O(1) вместо перебора списка. Авторы хранятся в **set**, а теги книги - во **frozenset**, так как там важна только уникальность значений, а frozenset сохраняет неизменяемость записи.

Ловушки с семинара обойдены: в аргументах по умолчанию нет изменяемых объектов (`tags=None`), коллекции создаются в `__init__` для каждого экземпляра, наружу отдаются копии (`list(...)`, `frozenset(...)`) вместо внутренних объектов, список не изменяется во время итерации по нему, а в качестве ключей используются только неизменяемые типы.

Запуск: `python tracker.py`
